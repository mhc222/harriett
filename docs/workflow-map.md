## How Harriett fits in the deal lifecycle

Every deal at Pritchett-Moore has two stages where Harriett helps.

**Stage 1: Pre-listing (win the listing)**
The agent asks Harriett before any paperwork exists. Presentation prep, CMA draft, listing copy, social content. Everything produced here is agent-facing only. No compliance gates apply.

**Stage 2: Active transaction (coordinate the deal)**
Harriett detects a new listing or contract and runs the five coordination workflows. In Phase 2, detection comes from the agent's Microsoft 365 inbox and Instanet notification emails. In Phase 3, dotloop adds a second structured trigger.

## Pre-listing workflow

**Trigger:** Agent request ("Harriett, I'm presenting on Academy Drive...")

| Step | Today | With Harriett |
|------|-------|---------------|
| Listing presentation materials | Agent assembles manually or skips | Harriett drafts a property-specific marketing flyer and self-promotion one-pager on request |
| MLS description / listing copy | Vicki drafts via office ChatGPT (address, highlights, ~10 photos, 800-char limit) | Harriett drafts in the individual agent's voice, respects MLS character limits, ready to paste |
| Social content | Agent writes generic post or skips | Harriett drafts Facebook/Instagram content matched to agent's tone |
| CMA preparation | Agent pulls comps manually, assembles in Excel or skips | Harriett assembles comp data into a draft CMA for agent review. Agent cleans dirty records (foreclosures, $0 sales) before use. Pricing is always agent-approved. |
| Property and seller research | Agent Googles or skips | Harriett surfaces property history, neighborhood data, and seller context to prep the pitch |
| Seller meeting notes | Voice memo or Otter, transcribed manually | Agent shares recording or notes; Harriett summarizes and converts to follow-up tasks |

**Time saved (estimated):** Not yet quantified. Scoped June 8 as the highest-priority surface.

## Alyssa's coordinator workflow (full detail)

These are the exact steps the coordinator runs today. Harriett's automation targets are noted.

### New listing

**Coordinator steps:**
1. Verify folder complete: signed listing agreement, other forms, photos, owner contact numbers, lockbox number, shackle code, CBS code. Email agent immediately if anything missing.
2. Receive and upload photos to Alyssa's computer.
3. Enter listing in MLS with photos. Convert provisional to active if needed.
4. Email MLS link to listing agent, cc Wilson and Gail.
5. Put listing in Agent News.
6. Log in Excel Master "Listings" list (emailed Wilson and Gail every Monday).
7. Make blue label for physical file folder.
8. Send Just Listed postcard. Email agent confirmation, copy Gail.
9. Place initial checklist inside folder cover.

**Executive admin steps:**
- Email broker letter to seller. Copy agent, cc Wilson and Gail.

**Harriett targets:** Steps 1 (checklist verification flag), 4 (draft email), 5 (draft Agent News entry), 8 (draft postcard copy + draft confirmation email).

**Agent checklist (must initial before file accepted):**
- Listing Agreement signed
- Listing Estimated Net Sheet
- PM RECAD Disclosure
- State RECAD Notification
- Dual Agency Agreement
- Designated Single Agency (Wilson must approve)
- Lead-Based Paint Form (required if pre-1978)
- PM Exclusive Listing Form
- Lock Box number, shackle code, CBS code, owner name, contact info, email

---

### Pending sale

**Coordinator steps:**
1. Hold earnest money check until agent confirms it is a contract.
2. Put sale in Agent News.
3. Make white label for file folder (place over blue if PM listing).
4. Log in Excel Master "Sales" list.
5. If PM listing: enter MLS Active to Pending; log contract date; take earnest money to Chanda (if agent approves); load final contract into Instanet.
6. If not PM listing: load final contract into Instanet.

**Harriett targets:** Steps 2 (draft Agent News entry), 4 (log to deal database), 5 (trigger MLS status task + Instanet load reminder).

**Agent checklist (must initial per offer):**
- Contract signed
- Net Sheet (required for every offer amount)
- Lead-Based Paint
- PM RECAD Disclosure
- State RECAD Notification
- Buyer's Agency
- Dual Agency
- Designated Single Agency (Wilson must approve)
- Signed HUD
- Concessions amount, selling agent + PSF, listing agent + PSF, pending date, closing date, property type

---

### Closed file

**Coordinator steps:**
1. Record closed date in Excel Master "Sales" list. Email Wilson.
2. Change MLS status from Pending to Sold.
3. Load HUD/settlement statement into Instanet.
4. Send Just Sold postcards. Email agent confirmation.

**Executive admin steps:**
1. If commission check: email agent when check signed and ready. Copy statement. Give or scan to Gail.
2. If direct deposit: email deposit slip to agent, copy Gail.

**Harriett targets:** Steps 1 (draft Wilson email, update deal record), 4 (draft postcard copy + agent confirmation), executive admin drafts.

## Overwatch layer (cross-cutting)

Agents asked for peace of mind across all pending deals at once. Harriett surfaces:

- Missing disclosures across the pipeline (RECAD, Lead-Based Paint, FHA addendum)
- Approaching deadlines (inspection window, closing date)
- Stalled steps (photographer not confirmed, title not contacted)
- Loan type changes (e.g. USDA to FHA is a material compliance event)

This is the dashboard view. It is not a single workflow. It runs across all five.

## What Harriett does not do

- Price properties or give pricing advice. CMA drafts are for agent review only. Pricing is always agent-approved.
- Send anything to a consumer without broker approval. Every outbound message goes through the approval queue.
- Replace Alyssa's MLS entry, file labeling, or physical file management.
- Handle earnest money. Chanda owns that.
- Make legal or compliance determinations. Harriett flags; agents and broker decide.
